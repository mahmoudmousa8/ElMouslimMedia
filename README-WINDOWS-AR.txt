تشغيل موقع El Mouslim Digital Marketing على ويندوز
==================================================

1) ثبّت Node.js إصدار 22.13 أو أحدث من:
   https://nodejs.org/

2) فك ضغط ملفات المشروع في مجلد مستقل.

3) شغّل الملف:
   START-WINDOWS.bat

4) انتظر حتى يظهر عنوان الموقع المحلي في النافذة، ثم افتحه في المتصفح.

5) افتح مجلد المشروع ببرنامج Visual Studio Code للتعديل.

أماكن تعديل المحتوى الرئيسية:

- بيانات الشركة والتواصل:
  data/site-config.ts

- الخدمات:
  data/services.ts

- الأعمال:
  data/projects.ts

- مقالات المدونة:
  data/blog-posts.ts

- الاشتراكات الرقمية:
  data/subscriptions.ts

- الوظائف:
  data/jobs.ts

ملحوظة:
التعديل على ملفات الديسكتوب لا يغيّر الموقع المنشور تلقائياً.
يجب رفع التعديلات إلى GitHub أو نشر النسخة الجديدة على منصة الاستضافة.
